# Our Family Tree

A modern family tree you can actually enjoy using — visual, warm, and easy.

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Start with an empty archive, then add yourself and grow the tree.

Trees save to the server when you are signed in. Share the invite code and passcode from Share — not the old FAMILY / PEACE starter codes.
